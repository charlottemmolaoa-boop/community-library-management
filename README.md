# Community Library Management System

A React/Vite student project for the BIWA2110 Web Application Development assignment.

## Features
- Dashboard with book totals, user totals, transactions and low-stock highlighting (fewer than 2 copies)
- Book create, update, delete and search
- Stock addition and borrowing transactions with quantity validation and history
- User create, update and delete
- Demo sign-in using a user's name and membership ID
- React Router navigation
- React hooks and Local Storage persistence
- Responsive CSS layout

## Run locally
1. Install Node.js LTS.
2. Open this folder in VS Code.
3. Open Terminal in this folder.
4. Run `npm install` (or `npm.cmd install` in PowerShell).
5. Run `npm run dev` (or `npm.cmd run dev` in PowerShell).
6. Open the localhost URL shown by Vite.

Demo sign-in: `Library Admin` / `ADMIN001`

Data is stored in the browser's Local Storage. Clearing browser storage removes the saved demo data. The sign-in is for demonstration only and is not secure production authentication.

## Before submission
- Run the app and test adding/editing/deleting books and users, stock transactions, login and page navigation.
- Add your own improvements and make sure you understand the code.
- Push the project folder to your own GitHub repository and submit that repository URL, as required by the assignment.
